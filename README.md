# Collaborative Canvas

Collaborative Canvas is a real-time drawing application developed as a university project in a team of two.

## Features

- User registration, login and logout
- Real-time collaborative drawing
- Multiple authenticated users can draw on the same canvas
- Pixel colors are stored and synchronized through Supabase
- Authentication using Supabase

## Technologies

- Flutter
- Dart
- Supabase
- Git & GitHub

## Collaboration

The project was developed collaboratively using GitHub. We worked with separate branches, commits and pull requests to implement and integrate different parts of the application.

The repository preserves the original development history to demonstrate the collaborative workflow and individual contributions.

## Project Context

University project developed during my Media Informatics studies at the University of Regensburg.
